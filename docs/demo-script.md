# Demo script (acceptance test)

8–10 minutes, run three times back-to-back before Gate 4. Each scenario has a backup video and a fallback.

| # | Scenario | Pass when | Backup |
| --- | --- | --- | --- |
| 1 | Wake word, then "What's around me?" | Short cloud scene description is spoken | Video; mock-mode answer |
| 2 | Walk toward an obstacle | Warning with near/medium/far, left/right, vibration | Video |
| 3 | Crowded room | Only the important item is spoken; alert log shows suppressed events | Projected alert log |
| 4 | Vehicle approaching from the side (toy car or recorded video) | Critical alert interrupts everything, no cloud | Video replay source |
| 5 | Read a sign, menu, medicine box (and EGP note if shipped) | Text read correctly | Printed test cards |
| 6 | Known enrolled person / unknown person (if shipped) | Name spoken / "someone you don't know" | Video |
| 7 | "Take me to the nearest pharmacy" | Turn-by-turn on the pre-tested route | GPX replay |
| 8 | "Open WhatsApp and read my new messages", "scroll down", "summarize these", summarize a Facebook post | Correct reading and summary | Mock screen app |
| 9 | Voice SOS | Countdown, cancel works, SMS with location reaches a team phone | Video |
| 10 | Airplane mode | Detection and warnings still work; after reconnect a cloud question is answered | — |

Rules: never stage scenario 4 near real traffic; only consenting people appear; second charged phone, power bank and hotspot ready.
